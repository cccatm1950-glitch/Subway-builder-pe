# Subway Builder Mobile Unofficial

An independent mobile subway-building game project built with **Godot 4** and **GDScript**.

## Project status

Early foundation stage. The first milestone establishes a clean, runnable Godot project before railway construction systems are added.

## Technology

- Godot 4
- GDScript
- Android export target
- OpenStreetMap-compatible geographic data is a planned feature, not yet implemented

## Open the project

1. Install Godot 4.
2. Clone or download this repository.
3. In Godot, choose **Import** and select the `project.godot` file.
4. Open the project and press **F6** to run the current scene, or **F6** after selecting the main scene.

## Beginner-friendly workflow

- Make one focused change at a time.
- Run the project after each change.
- Keep gameplay systems separate from interface systems.
- Do not add external map services or API keys until the basic prototype works.

## Planned milestones

1. Project foundation and launch screen.
2. Mobile viewport and camera controls.
3. Track geometry and station placement.
4. Junctions, parallel tracks, and platforms.
5. Service lines and train movement.
6. Map data and optional 3D presentation.
7. Android export and device testing.
